# ドキュメント

hello-typescript-vitest は、Vitest で TypeScript をテストするサンプルです。まず「準備」を読み、次に動かしたいテストのページを読んでください。

## ページ

- [準備](setup.md) — Node、依存、ブラウザーのテストに使うブラウザー、開発用コンテナ
- [ToDo アプリ](todo-app.md) — ブラウザーのテストと VRT が相手にするアプリ。何ができるかと、開き方
- [ビジュアルリグレッションテスト](visual-regression.md) — 固定した Playwright サーバー、テストの実行、結果の見方

## このドキュメントの書き方

どのページも、英語（`docs/en/`）と日本語（`docs/ja/`）に同じファイル名で置き、1 行目にもう一方の言語へのリンクを書きます。変えるときは、同じ PR で両方の言語を直してください。`npm run lint:docs` は、相手のいないページ、1 行目がそのリンクでないページ、見出しのレベルやコードブロックの言語の並びが相手と違うページ、切れた相対リンクを見つけると失敗します。文章そのものは比べません。
